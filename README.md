# Play

Playは、音楽サービスの保存一覧、検索、作品の詳細と端末内再生を扱う開発中のAndroidアプリです。

楽曲はPlay内で再生します。ログイン後の再生にペアリングやSDK用アプリの登録、外部プレイヤーの操作は必要ありません。

## 使い方

ログイン済みの場合は手順4から利用できます。

1. Playを起動し、「ログイン」を押す。
2. 自動で開くサービスのログイン画面で、通常のログインを完了する。
3. ログイン結果は同じ端末のPlayへ自動で戻る。再生用のペアリングコードや別端末の操作は必要ない。
4. 「プレイリスト」「アルバム」「楽曲」から保存一覧を開く。「検索」では3種類をまとめて検索する。
5. 一覧の項目を押して作品の詳細や収録曲を開く。「再生」または収録曲を押して再生を開始する。
6. 画面下部から一時停止、前後の曲、シーク、リピート、ランダム再生を操作する。シークバーはタップとドラッグに対応する。
7. 取得に失敗した場合は、エラーを閉じて通信状態を確認し、「更新」を押す。

プレイリスト画面の作成ボタンから、非公開のプレイリストを作れます。自分が所有するプレイリストは詳細画面から名前・説明・画像を編集できます。選んだ画像は正方形に整えられます。削除は確認画面を経てライブラリから取り除きます。

認証情報は端末のKeystoreで暗号化して保存し、有効期限が近づくと自動で更新します。パスワードはサービスのログイン画面で入力します。通常ログインの完了後、曲の再生に追加の接続設定は行いません。

旧試作版の保存認証では、初回に通常ログインへの切り替えが必要な場合があります。ブラウザーにログイン状態が残っていれば、それを利用できます。切り替えをキャンセルしても以前の保存情報は残ります。

画像は最大128 MiB、音声ストリームは最大512 MiBまでキャッシュし、上限に達すると古い内容から削除します。音声は暗号化された配信データを保存し、再生時にサービスの認証と端末のDRMを使います。

2026-09-13に、実機で通常ログインの保存と更新、検索・作品詳細・画像表示、約5分の曲の最後までの背景再生、シーク・前後移動・リピート・ランダム再生、プレイリスト編集を確認しました。検証対象と条件は[検証手順](verification.md)を参照してください。

## ビルド

前提:

- JDK 17以上
- Android SDK Platform 37 / Build Tools 37.0.0

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

生成APKは `app/build/outputs/apk/debug/app-debug.apk` です。
