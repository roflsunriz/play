# Play

Playは、ライブラリ、プレイリスト、楽曲、検索、再生を扱うミュージックプレイヤーです。

Android 7.0以降で利用できます。

## ダウンロード

[リリース](https://github.com/roflsunriz/play/releases)

## 使い方

1. Playを起動し、「ログイン」を押す。
2. メールアドレスとメールアドレスに届くOTPコードを入力する。
3. 楽曲を楽しむ。

### お気に入りとプレイリスト

プレイリスト一覧の先頭にある「お気に入りの曲」から保存曲を開けます。曲やアルバムの丸い＋ボタンで「お気に入り追加」、保存済みのチェックボタンで「お気に入りから削除」を選びます。変更はログイン先のライブラリにも反映されます。

「プレイリストに追加」を選ぶと、検索欄と編集できるプレイリストが表示されます。チェックがないリストを押すと追加、チェックがあるリストを押すと削除します。アルバムでは全収録曲を対象とし、追加時は未登録の曲だけを入れます。

曲のメニューから「ソングラジオに移動」「アーティストに移動」も使えます。検索結果は「すべて」「曲」「プレイリスト」「アルバム」「アーティスト」「ポッドキャスト＆番組」「ジャンル＆気分」で絞り込めます。

### スリープタイマー

ハンバーガーメニューから「スリープタイマー」を開き、経過時間（時間・分）か時刻を指定します。指定時間に5秒かけて音量を下げ、停止後に画面を消灯・ロックします。再生が終了している場合は消灯・ロックだけを行います。

初回は画面内の案内に従って画面ロックと、必要な端末では正確なアラームを許可してください。設定済みのタイマーは同じ画面で変更・解除できます。端末の再起動で解除されます。詳しくは[スリープタイマー](docs/sleep-timer.md)を参照してください。

## ビルド

前提:

- JDK 17以上
- Android SDK Platform 37 / Build Tools 37.0.0

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

生成APKは `app/build/outputs/apk/debug/app-debug.apk` です。
