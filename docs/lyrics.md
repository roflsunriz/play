# 同期歌詞

曲の詳細画面を下へスクロールすると配信歌詞を表示する。時刻付きの歌詞は再生位置に応じて現在行を強調し、自動で追従する。手動ドラッグ、スクロール操作、アクセシビリティのスクロールで追従を解除し、「同期する」で現在位置へ戻せる。行を押すと、その曲の指定位置から再生する。

現在の再生曲と表示中の曲が異なる場合は、別の曲の再生位置で歌詞を進めない。歌詞の曲を選んだ場合には、その曲を指定時刻から再生する。読み込み中の曲変更、再試行、遅延応答でも以前の曲の結果を混ぜない。

配信元の行・時刻・同期種別・出典表示を使う。`LINE_SYNCED`と`SYLLABLE_SYNCED`は行の開始時刻に同期する。終了時刻には次の行の開始を使い、古い`endTimeMs`で途中から強調を消さない。時刻のない歌詞では同期・シーク操作を無効にする。

未配信、空の歌詞、配信制限、通信失敗は別々に表示する。配信元名を保持し、本文をログ、テストfixture、Gitへ保存しない。画面テストは独自の合成文だけを使う。

## 検証

- `LyricsApiClientTest`：要求・型、開始時刻、取得不能、制限、未知の同期形式、エラー、出典を検査する。
- `LyricsPanelTest`：進行・シーク、自動スクロール中のドラッグ、ScrollBy/ScrollToIndex、同期復帰、曲変更、配信状態を検査する。
- `PlaybackSettingsScreenTest`：曲詳細からその曲の歌詞slotへ接続し、アルバム詳細へ誤接続しないことを検査する。
- `LyricsAccountTest`：`liveLyrics=true`と配信対象の`trackUri`を明示し、実データの同期形式・行数・時刻だけを確認する。歌詞本文は出力しない。
