# 同期歌詞

拡大プレイヤーを下へスクロールすると再生中の曲の配信歌詞を表示する。公式の配信歌詞とLRCLIBの歌詞をタブで切り替えられる。LRCLIB側は曲名・歌手名・アルバム・再生時間を照合し、別曲の歌詞を表示しない。不一致・未配信・演奏のみ・空応答は未配信として扱い、取得失敗は再試行できる。時刻付きの歌詞は再生位置に応じて現在行を強調し、自動で追従する。手動ドラッグ、スクロール操作、アクセシビリティのスクロールで追従を解除し、「同期する」で現在位置へ戻せる。行を押すと、その曲の指定位置から再生する。再生していない曲の詳細画面には歌詞を置かない。

歌詞は再生中の曲だけに表示し、曲が変われば取得し直す。読み込み中の曲変更、再試行、遅延応答でも以前の曲の結果を混ぜない。

配信元の行・時刻・同期種別・出典表示を使う。`LINE_SYNCED`と`SYLLABLE_SYNCED`は行の開始時刻に同期する。終了時刻には次の行の開始を使い、古い`endTimeMs`で途中から強調を消さない。時刻のない歌詞では同期・シーク操作を無効にする。

LRCLIBは認証不要の副次経路である。`/api/get`へ曲名・歌手名・アルバム・秒数を送り、`plainLyrics`・`syncedLyrics`（LRC）を受ける。LRCの時刻・オフセット・複数時刻を解釈し、メタタグ行を除いて開始時刻順に並べる。404は未配信、400は再試行なし、429/503は`Retry-After`（上限30秒）または短い指数待機で最大2回送り直す。

未配信、空の歌詞、配信制限、通信失敗は別々に表示する。配信元名を保持し、本文をログ、テストfixture、Gitへ保存しない。画面テストは独自の合成文だけを使う。LRCLIBの応答も本文を記録せず、メモリー内だけで扱う。

## 検証

- `LyricsApiClientTest`：要求・型、開始時刻、取得不能、制限、未知の同期形式、エラー、出典を検査する。
- `LrclibApiClientTest`：LRCの時刻・メタタグ・オフセット・複数時刻、曲名・歌手・アルバム・再生時間の照合と不一致拒否、404・400・500・429の扱いを検査する。実歌詞は使わない。
- `LyricsPanelTest`：進行・シーク、自動スクロール中のドラッグ、ScrollBy/ScrollToIndex、同期復帰、曲変更、配信状態を検査する。
- `LyricsTabsTest`：公式とLRCLIBのタブ切替、同期行の強調、非同期表示、未配信時の表示を検査する。実歌詞は使わない。
- `PlaybackSettingsScreenTest`：拡大プレイヤーが再生中の曲の歌詞slotへ接続することを検査する。
- `LyricsAccountTest`：`liveLyrics=true`と配信対象の`trackUri`を明示し、実データの同期形式・行数・時刻だけを確認する。歌詞本文は出力しない。
