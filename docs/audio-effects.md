# 音質設定の設計

## 操作と保存

メニューの「音質設定」から、プリアンプと30バンドのイコライザーを操作する。初期状態は無効で、設定全体の有効・無効を切り替えられる。

- プリアンプは−10〜+10dB、各バンドは−12〜+12dB。中心周波数は25Hz〜20kHzの30点で、正本は`EqualizerBands`。
- 7つのプリセットは調整の開始点として使い、その後も各値を編集できる。
- 保存スロットは5個。現在のプリアンプ・全バンド・有効状態を名前とともに保存し、呼び出し、上書き、名前変更、削除ができる。名前は空白を除いた先頭・末尾を整え、1〜40 Unicodeコードポイント、制御文字を含まない値にする。
- 設定は端末単位で保持する。スライダー変更はメモリーへ即時反映し、150msの間隔で変更が落ち着いた後にIOスレッドで保存する。スロット変更と画面を閉じる操作は保存を早める。
- JSON schema 1で現在値と5スロットを一括保存する。配列数、有限値、範囲、名前、設定文字列長32,768以内を検証する。破損や未対応形式はこの設定キーだけ初期化する。
- 保存失敗でも操作中の設定を戻さない。画面に失敗を示し、現在値を保って保存を再試行する。書き込み完了の結果を確認するため、IO上でchecked `commit()`を使う。

## 音声経路

Media3が復号・デコードしたPCMを`EqualizerAudioProcessor`へ通し、その後にAudioTrackへ渡す。DRMの認証、鍵の保持、復号は従来どおりAndroidとMedia3が担当する。音声や音声鍵を保存・出力する処理は追加しない。

端末の標準Equalizerが提供するバンド数に依存せず、30個のpeaking biquadを使用する。係数は[W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)の式に従う。Qは公称1/3オクターブに対応する`1 / (2 sinh(ln(2) / 6))`とし、ナイキスト周波数以上の中心は別の周波数へ移さず無変更とする。

チャンネルごとに独立したフィルター履歴を保持する。設定変更は2系統の出力を20msで混ぜて切り替え、切り替え中の新しい操作は最新値へ集約する。係数の極を直接補間しない。シーク、flush、サンプルレート変更時は履歴を破棄する。

定常的に無効または完全フラットな場合はPCMをバイト単位でそのまま渡す。有効時の過大な出力は16bitの範囲へ制限し、整数の反転を防ぐ。複数帯域を大きく上げると音が歪む場合があるため、プリアンプを下げて余裕を確保できるようにする。

[Media3 1.11.1 DefaultAudioSink](https://github.com/androidx/media/blob/1.11.1/libraries/exoplayer/src/main/java/androidx/media3/exoplayer/audio/DefaultAudioSink.java)では、カスタム音声処理はPCMの経路に適用される。float出力、圧縮音声の直接出力、offloadで処理が迂回されないように設定し、`ToInt16PcmAudioProcessor`の後にEQを接続する。再生中の有効化でも再生エンジンを作り直さない。

## 検証

`EqualizerDspTest`は30中心の実周波数応答、プリアンプ両端、左右分離、分割バッファ、フラットの同一性、切り替え、flush、複数のサンプルレートを確認する。`EqualizerAudioProcessorTest`はMedia3の実APIとの接続と出力計測を確認する。

`AudioEffectsStoreTest`は5スロット、通常の自動保存、再構築、上書き・名前変更・削除、破損復旧、失敗と再試行、UIスレッドでIOをしないことを検証する。実音源は`LiveEqualizerTest`を`liveEqualizer=true`で実行し、同じ区間の復号後音量が−6dB変化することを測る。`AudioOutputTest`に`liveAudio=true`、`fullTrack=true`、`thirtyBands=true`を渡すと、30バンドを有効にしたまま背景再生の中盤・終盤と自然終端を確認する。どちらも終了時に元の音質設定を戻す。
